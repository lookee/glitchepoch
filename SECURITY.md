# Security policy

Please **do not disclose security vulnerabilities in public issues**.

Use GitHub's **Report a vulnerability** / private vulnerability reporting feature, if enabled for this repository. Otherwise, contact the project maintainer privately through the contact information on [lucaamore.com](https://www.lucaamore.com/).

Supported version: the latest tagged release.

We aim to triage reproducible vulnerability reports and publish fixes responsibly. This project is maintained on a best-effort, volunteer basis.
