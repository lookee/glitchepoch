# Contributing to GlitchEpoch

Thanks for considering a contribution.

1. Search existing issues and pull requests before proposing a change.
2. Open a focused issue for substantial feature proposals.
3. Keep changes dependency-free, accessible, fast, and compatible with WordPress.
4. Write code, documentation, comments, issue descriptions, and commit messages in English.
5. Run `php -l glitchepoch.php`, `php tests/smoke.php`, `node --check assets/js/glitchepoch.js`, `node --test tests/counter.test.cjs`, and `python3 -m unittest discover -s tests -p "test_*.py"` before opening a pull request.
6. Include a clear description and screenshots when changing the appearance.
7. Do not add telemetry, tracking, third-party frontend requests, or advertising.

By contributing, you agree to license your contributions under the project's GPL-2.0-or-later license.
